# LLM Study Guides

A beginner's course on large language models in eight self-contained, interactive HTML pages. Open `index.html` in any browser to start.

| Part | File | Topic |
|---|---|---|
| Hub | `index.html` | How to use the series, learning map, study plan, master glossary |
| 1 | `01-how-llms-work.html` | Tokens, next-token prediction, context window, training, temperature, hallucination |
| 2 | `02-prompt-engineering.html` | System prompts, few-shot, chain-of-thought, structured output, prompt patterns |
| 3 | `03-rag.html` | Retrieval-augmented generation: chunking, embeddings, vector search, reranking |
| 4 | `04-tools-and-agents.html` | Function calling, the agent loop, agent patterns, memory, MCP, guardrails |
| 5 | `05-evals.html` | Evaluation: datasets, graders, metrics, benchmarks, pitfalls, the eval loop |
| 6 | `06-fine-tuning.html` | When to fine-tune, LoRA, datasets, loss curves, serving |
| 7 | `07-safety-and-security.html` | Prompt injection, jailbreaks, leakage, layered defences, red teaming, OWASP |
| 8 | `08-production.html` | Streaming, latency, cost, caching, fallbacks, observability, releases |

Every guide has diagrams, interactive playgrounds, a quiz, and a glossary of every technical term it uses. The pages need no server and no build step; fonts load from Google Fonts when online and fall back to system fonts offline.
